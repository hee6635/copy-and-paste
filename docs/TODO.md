## 방향 (2026-11 검수)
링크메모는 깊이(영상 · 댓글 · 화면 글자)는 경쟁 앱보다 앞섬. 약점은 "AI 정리가 실패하거나 얇게 나옴" → 기능 늘리기보다 안정화 먼저.
1. 안정화: AI 2단계 · 끊긴 답 살리기 · 폰 확인 체크리스트 · (고민) 결제 연결 · 큰 파일 나누기(Gemini.kt · SaveService.kt · app.css · MainActivity.kt)
2. 꺼내 쓰기: 다시 보기 · 지도 · 한 장씩 정리 연결
3. 넣기 넓히기: 스크린샷 · 사진 저장(지금은 링크만) · 인스타 저장함 가져오기 · 틱톡 · 스레드
4. 안전: 휴지통 · 드라이브 자동 백업
하지 않음: 서버 · 웹 버전 · MCP · 소셜 (무료 · 폰 안이라는 장점과 부딪힘)
