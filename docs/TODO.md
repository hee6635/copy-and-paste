- ✅ 공유로 저장 (인스타 · 유튜브 · 웹) + 저장 창 (영상까지 / 링크만 · 한 줄 메모)
- ✅ 설명 · 댓글 20개 · 썸네일 · 영상(기본 720p) 저장
- ✅ 카드 홈 · 검색 · 태그 · 상세 · 내 메모
- ✅ 하단 버튼: 링크로 이동 · 원본 저장 · 복사 · txt · 삭제
- ✅ 장면 캡처 + 화면 글자 읽기(폰 안에서)
- ✅ 설정: 인스타 로그인 · 화질 · 저장 공간 · 영상 도구 업데이트
- ✅ 검사 페이지 (설정 › 검사 · 실패 카드 › 원인 검사): 단계별 ✓/✕ + 이유 + 결과 복사
- ✅ 인스타 댓글: 보이지 않는 인스타 화면에서 가져오기 → 안 되면 직접 요청 · 실패 이유 저장 · 다시 가져오기
- ✅ 복사 고르기 (전체 · 설명/본문 · 댓글 · 내 메모 · 링크)
- ✅ 꾹 눌러 여러 개 고르기 → 폴더 이동 · 순서 바꾸기 · 삭제
- ✅ 폴더 2단계 (여행 › 나트랑): 홈 칩 2줄 · 칩 꾹 누르면 이름 바꾸기/안에 만들기/앞으로/지우기
- [ ] 폰에서 확인: 인스타 릴스 · 사진 게시물 · 유튜브 쇼츠 · 일반 웹

## 2단계 (Gemini)
- ✅ 2-1: 저장하면 Gemini(gemini-flash-latest)가 요약 · 태그 · 폴더 추천([옮기기]) · 댓글 꿀팁 · 정보 댓글 ★ · 레시피/체크리스트 · 받아쓰기(영상 있을 때) · 설정에 키 · 켜기 · 사용량 · 예전 것 정리 · 검사에 Gemini 단계
- AI 요약 · 받아쓰기 전문 · 자동 태그/카테고리 · 레시피/체크리스트 정리
- 댓글 중요 정보 정리: 정보가 있는 댓글 ★ 표시 + 댓글 · 작성자 답글에서 꿀팁만 뽑아 요약 (태그 · 이모지만 있는 댓글은 뒤로)
- AI 핵심 장면 자동 캡처
- 홈에서 끌어서 순서 바꾸기 (꾹 눌러 떼면 고르기 · 꾹 눌러 끌면 이동) — ≡ 목록 방식과 비교
- AI 사용량 화면: 오늘 · 이번 달 모델별 횟수 · 토큰 (앱이 직접 셈) · 429 오류에서 어떤 한도(분당/하루)에 걸렸는지 · 초기화 시각(태평양 자정 = 한국 오후 4~5시) · 대략 한도는 설정에서 고칠 수 있게
- ✅ 영상 보고 정보 뽑기 (0.11): "링크만" 저장한 것도 AI가 영상을 봄 — 유튜브는 링크를 Gemini에 바로 넘김(내려받기 없음), 인스타는 잠깐 받아서 보내고 지움 · 화면 글자 · 말 · 장면에서 정보 추출 · 설정에서 켜고 끄기
- 영상 보기 빠르게: AI용 임시 영상은 360p · 가장 작은 화질로 (21MB → 5~8MB, 올리기 8초 → 2~3초) · "영상이 길어서" 이유 기준 높이기(5천 → 3만 토큰)
- 큰 키워드 편집: 타일 꾹 누르면 지우기(숨기기) · 이름 바꾸기 · 끌어서 순서 이동 · 내 키워드 추가 · 메모의 키워드 바꾸기(AI가 잘못 정했을 때)
- 내 저장함에 질문하기
- 분류 규칙: 키워드 규칙("나트랑" 있으면 → 여행 › 나트랑) + 대화로 규칙 만들기("지금부터 나트랑 얘기는 나트랑으로") → 확인 받고 적용 · 기존 것도 옮길지 묻기 · 규칙 목록에서 고치기
